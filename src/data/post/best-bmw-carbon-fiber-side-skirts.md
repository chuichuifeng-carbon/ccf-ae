Для боковых порогов важны длина кузова и точки крепления, затем — сочетание с остальными элементами автомобиля. В подборке CCF шесть вариантов семейства G8X и один для G90. Седан, купе и кабриолет рассматриваются отдельно.

## 1. CCF — пороги BMW G80/G82 в стиле 3D

Вариант 3D позволяет сопоставить линию борта с остальным аэродинамическим обвесом. Укажите исполнение кузова и количество деталей в поставке.

[Боковые пороги 3D Style для BMW M3 / M4 G80 G82 — Настоящий сухой карбон](/products/bmw-g80-g82-3d-style-side-skirts)

## 2. CCF — пороги BMW G80/G82 в стиле AX

AX рассматривают для согласования боковой части с выбранной передней. Совпадающее название стиля не заменяет проверку креплений.

[Боковые пороги AX Style для BMW M3 / M4 G80 G82 — Настоящий сухой карбон](/products/bmw-g80-g82-ax-style-side-skirts)

## 3. CCF — пороги BMW G80/G82/G83 в стиле MP

В названии этого референса присутствует G83 наряду с G80/G82. Передайте тип кузова и фотографии, чтобы определить поставляемую версию.

[Боковые пороги для BMW](/products/side-skirts)

## 4. CCF — пороги BMW G80/G82 в стиле OEM

OEM Style — обозначение дизайна в каталоге независимого поставщика. Оно не означает оригинальную деталь BMW.

[Боковые пороги OEM Style для BMW M3 / M4 G80 G82 — Настоящий сухой карбон](/products/bmw-g80-g82-oem-style-side-skirts)

## 5. CCF — пороги BMW G80/G82 в стиле R44

R44 можно сравнить с AX и 3D по виду всей боковой линии. До расчёта количества определите единицу продажи и состав обеих сторон.

[Боковые пороги R44 Style для BMW M3 / M4 G80 G82 — Настоящий сухой карбон](/products/bmw-g80-g82-r44-style-side-skirts)

## 6. CCF — плоские пороги BMW G82/G83

Плоский вариант имеет применение G82/G83 в названии. Для седана G80 требуется отдельное подтверждение поставщика.

[Боковые пороги для BMW](/products/side-skirts)

## 7. CCF — пороги BMW G90 M5 в стиле MP

Это отдельное применение M5 G90. Размеры и крепления порогов M3/M4 нельзя переносить на него по аналогии.
