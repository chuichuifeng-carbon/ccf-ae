# 阿拉伯语 B2B 站优化记录

日期：2026-10-30。范围：本地 Astro 项目，未发布线上。

## 已完成

- 修复双向文字处理函数的空值崩溃，以及按钮异步插槽和链接参数的类型错误。
- 首页首屏采用 WhatsApp 主 CTA；全站 WhatsApp 链接附带页面标题与标准网址，目录询盘保留具体车型和 PDF 上下文。
- 启用移动端底部 WhatsApp 按钮，清理组件卸载后的滚动监听，并预留底部空间。
- 六大品牌及其他车型共 78 个去重 PDF 入口。文件继续由主站托管，本地提供阿拉伯语导航与询价入口。
- 44 个具体产品卡片换成各自产品页面公布的对应图片，并本地压缩为 WebP。
- 新增 4 个阿拉伯语产品详情页：G80/G82 R44 前唇、CSL 三段式前唇、MP 后扩散器、G87 M2 机盖。
- 产品选项基于主站已公布资料与目录；DCF 保留原标签，目录序号不标成 SKU。未添加价格、库存、年份适配或技术工艺推断。
- 补充工厂照片、视频入口、3 组客户装车与原始消息、5 份核验/认证资料；客户案例图片改用对应案例的主站图片。
- 联系、批发、OEM/ODM 和新产品页提供阿拉伯语 WhatsApp 询价准备表单。它在浏览器内生成消息，由买家在 WhatsApp 中最终发送，不是已接入邮件后端的表单。
- 增加 `ccf:inquiry-click` 自定义事件；若网站配置并加载了 gtag，则上报 `inquiry_click`。不在事件里传递消息正文或公司信息。
- 删除首页“一小时回复”的固定承诺；移除未经运营确认的阿拉伯语客服语言声明。
- 修正将 Forged Carbon 外观描述为制造工艺的措辞，统一部分前唇名称。

## 来源与可复核资料

- `sources.json`：主站页面与公开图片、PDF 链接。
- `asset-manifest.json`：产品及公司资料图片的来源/本地路径映射。
- `case-assets.json`：客户案例图片来源。
- `catalog-link-check.json`：78 个 PDF 链接的 HTTP HEAD 检查，检查时全部返回 200。
- `scripts/verify-b2b.mjs`：生产 HTML 的内部链接、图片、语言、H1、目录落点和 WhatsApp 上下文检查。
