## 已实施的页面分工

| 原词方向                                         | 本站承接页        | 本次改进                                                                                            |
| ------------------------------------------------ | ----------------- | --------------------------------------------------------------------------------------------------- |
| manufacturer / factory / auto parts manufacturer | 首页 `/`          | 明确 CCF 中国制造商、售后改装件范围及目录采购/项目开发分流；增加 RFQ 入口                           |
| supplier / wholesale / components supplier       | `/grow/wholesale` | 说明逐参考款数量、样品、混合订单、包装目的地与按规格补货；不承诺统一 MOQ                            |

| BMW carbon fiber parts supplier                  | `/vehicles/bmw`   | 补充底盘、车身、ACC、排气等确认项；解释 CCF 独立售后件身份，不暗示 BMW 官方授权                     |

五页分别增加对应的三项采购说明，并以明确问题链接到相关指南；各页 meta description 同步更新。保留现有 URL，不按英文表中的建议路径批量新建重复落地页。`ProcurementHelp.astro` 只在指定页面渲染，内容由 `procurement-help.json` 按路由管理。

## 新增阿拉伯语指南

1. `/carbon-fiber-parts-rfq-checklist`：询价前需要提供什么资料；区分目录采购与新开发，按参考款说明数量、目的地及报价范围。
2. `/carbon-fiber-parts-moq-guide`：MOQ 为何随参考款、样件、混合订单、品牌包装或新模具不同；不虚构最低数量。
3. `/oem-vs-aftermarket-carbon-fiber-parts`：解释汽车原厂件、OEM Style 命名与 OEM/ODM 合同制造服务的区别；不把 CCF 描述为汽车品牌官方供应商。

三篇均包含作者、TDK、图片说明、站内采购/产品/政策链接和 WhatsApp 入口。更新相应页面的反向入口以及实际生成的第 4 页分页元数据；制造标签仍为三页，不创建不存在的分页。

## 未作为现有能力承诺的词

本次没有修改产品已确认参数，没有创建固定价格或交期，没有新增本地表单，也未推送 GitHub 或部署。
