- 产品及分类的 72 条记录与 SEO 计划同步，全站 120 页进入相同元数据/站点地图/图片站点地图/QA 数据源。恢复显式 sitemap 白名单，避免未登记页面自动放行。

## 导入后的维护

`scripts/scan-products.mjs` 使用 `src/data/b2b/product-content.ts` 的共同映射。导入后自动调用 `scripts/sync-product-seo.mjs`，保留已发布产品及 URL，生成完整短句而不机械截断。遇到未知部件名称或重复 SEO 标题会停止，要求补映射，防止再次把未知产品归成前唇。

`scripts/verify-product-pages.mjs` 纳入 `npm run check:products` 和 GitHub Actions。校验历史 URL、重复 TDK/H1、孤立产品、分类入口、所有内部目的地址、错误 HTML 文本、图片站点地图、公司实体及未经证实的价格/退货声明。还验证当前数据再次经过共同映射时保持稳定。

注意：未真实提供逐产品价格或评价时，Product 基本语义不等于已满足 Google 产品富结果资格；不为通过富结果检测而补造报价或评价。
